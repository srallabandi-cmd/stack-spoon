# Storyboard — 8 scenes (≈62s · 1280×720)

**Style lock (all scenes):** Photoreal product UI metaphor, soft daylight or cool slate workspace, shallow depth of field where helpful, calm camera (slow push / gentle pan). No purple neon, no holographic AI brains, no cyberpunk.

**Per-clip target:** 6–8s Seedance generations → trim in edit to timings below.

**§8 Connector Hub lock:** Visual logo grid · **Connect [App]** language · OAuth spoon-feed · never MCP jargon.

---

## Scene 1 — Pain: tool sprawl  
**Time:** 0:00–0:08 · **Duration generate:** 8s  

**Visual:** Overhead of a busy product desk: laptop with 6+ overlapping app windows (chat, tickets, docs, calendar), phone with Slack badges, sticky notes, half-empty coffee. Slow push-in.  

**On-screen:** *Too many tools. Too little context.*  

**Transition out:** Soft dissolve / slight blur wipe

**Transition out:** Hard cut to role grid

## Scene 4 — Connector Hub (§8 hero beat)  
**Time:** 0:20–0:34 · **Duration generate:** 10–12s (or 2× 6–8s clips)  

**Visual A — Logo grid (≈0:20–0:26):**  
Workspace **Apps / Connector Hub** screen. Clean 5-tile logo grid:

1. Slack — button **Connect Slack**  
2. Google Calendar (or Outlook) — **Connect Calendar**  
3. Granola (or Zoom) — **Connect Granola**  
4. Linear (or Jira) — **Connect Linear**  
5. Notion (or Confluence) — **Connect Notion**  

Status chips start as **Not connected**. Soft ambient UI light. Slow pan across the grid.

**Visual B — OAuth spoon-feed (≈0:26–0:34):**  
Cursor clicks **Connect Slack** → stylized Slack OAuth consent (“Allow access”) → channel picker (“#product, #eng”) → tile flips to green **Connected**. Remaining tiles cascade to Connected (quick montage). No terminal, no JSON, no “MCP”.

**On-screen:** *Connector Hub* · *Connect Slack* · *Connected*

**Transition out:** Slide left to Inbox  

**Split option:** Generate as Scene 4a (grid) + Scene 4b (OAuth) if Seedance quality drops on multi-beat clips.
